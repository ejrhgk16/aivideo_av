# AI DRAMA — 모바일 앱 디자인 체험

약 1분 길이의 AI 드라마를 제공하는 iOS·Android 앱을 위한 반응형 웹 구현입니다. 서비스 이름은 작업용입니다. 표지 3종은 이 프로젝트를 위해 AI로 제작한 콘셉트 이미지입니다.

## 구현된 흐름

- 홈 추천, 최신, 편집부 랭킹, 장르와 검색
- 하단 추천 탭에서 작품별 예고·1화를 화면 단위로 위아래 스크롤. 한 번에 한 카드만 재생하며, 팝업·공유·탭 이탈·본편 진입 중 정지. 돌아오면 카드 위치와 재생 위치 유지.
- 작품 소개와 회차 목록, 저장한 작품, 시청 기록과 이어보기
- 자막·속도·재생 위치를 조작하는 재생 화면 체험
- 작품별 처음 7~10화 무료, 이후 10P로 회차 열기
- 광고 보상 +10P, 100/300/600P 충전 체험, 이용 내역
- 확인 전 차감하지 않으며 열린 회차를 다시 볼 때 중복 차감하지 않음
- 미리보기에서 본편 진입 후 돌아가기, 본편 시청 위치와 미리보기 기록 분리

## 체험 범위

실제 드라마 영상, 광고 네트워크, 앱스토어 결제, 회원 서버는 연결되지 않았습니다. 재생 화면은 콘셉트 표지와 예시 자막으로 동작하며 영상 송출을 가장하지 않습니다. 충전은 실제 금액을 청구하지 않습니다. 예시 가격은 확정 요금이 아닙니다.

포인트·열린 회차·보관함·시청 기록은 현재 브라우저의 localStorage에만 저장됩니다. 결제 권한이나 유료 콘텐츠 보호에 사용할 수 없습니다. 상용 버전에서는 서버에서 영수증과 광고 보상을 확인하고, 회차 이용 권한 및 포인트를 일관된 거래로 처리해야 합니다. iOS/Android 설치 패키지를 포함하지 않습니다.

창작마당, 이용자 업로드, 카페, AI 채팅, 구독, 다운로드는 이번 범위에서 제외했습니다.

## 디자인 기준

- 한글: Pretendard Variable. 로컬 웹폰트와 라이선스 동봉.
- 배경 #0B0C0F / 본문 #F7F7F2 / 강조 #CBF46A
- 모바일 좌우 22px, 기본 버튼 48~50px, 홈·추천·찾기·보관함·내 정보 5개 메뉴
- 큰 표지, 간결한 제목, 적은 장식과 일관된 버튼·팝업·회차 스타일
- 모바일 기기 하단 여백, 키보드 초점, 팝업 초점 이동, 모션 줄이기 설정 반영

## 개발

원래 생성된 Sites / vinext / React 및 설치된 shadcn 구성요소를 유지합니다. `pnpm dev`, `pnpm build`를 사용합니다. 외부 API 키는 필요 없습니다.

## 추천 미리보기 영상 연결

lib/dramas.ts의 previewSources에 작품별 실제 영상 주소(src)와 한국어 자막 주소(captions)를 함께 지정할 수 있습니다. 현재는 주소가 없으므로 콘셉트 표지와 예시 자막으로 표시합니다. 실제 미디어는 playsInline·기본 음소거로 재생하고, 비활성 카드는 정지하며, 로드 실패 시 표지와 실패 안내를 표시합니다. 추천 피드는 본편 시청 기록을 쓰거나 포인트를 사용하지 않습니다.
