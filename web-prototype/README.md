# peeka — 모바일 앱 디자인 체험

약 1분 길이의 AI 드라마를 제공하는 iOS·Android 앱을 위한 반응형 웹 구현입니다. 서비스 이름 peeka는 작업용이며 '몰래 엿보는(peek) 재미'에서 왔습니다. 표지 8종은 이 프로젝트를 위해 AI로 제작한 콘셉트 이미지입니다.

## 구현된 흐름

- 홈 추천, 랭킹, 장르와 검색(띄어쓰기·대소문자를 가리지 않음, 순위순·최신순 정렬)
- 하단 빼꼼 탭에서 작품별 1화 미리보기를 화면 단위로 위아래 스크롤. 미리보기는 표지 위의 자막 장면 세 개이고, 보고 있는 카드만 4초마다 다음 장면으로 넘어간다(세 칸 막대로 직접 고를 수 있다). 장면 넘김을 멈추면 피드 전체가 멈추고, 다른 작품으로 넘겨도 다시 누를 때까지 멈춰 있다. 팝업·공유·탭 이탈·회차 재생 중에는 멈추고, 모션 줄이기에서는 멈춘 채로 시작한다. 돌아오면 카드 위치와 보던 장면 유지.
- 작품 소개와 회차 목록, 저장한 작품, 시청 기록과 이어보기(진행 막대는 보던 장면 / 4, 다 본 회차만 100%). 마지막 화까지 다 본 작품은 홈의 이어보기와 떠 있는 이어보기 막대에서 빠지고 보관함의 시청 기록에만 남는다
- 시청 기록 지우기: 보관함 시청 기록의 줄 끝 × 버튼으로 한 작품씩 지우고, 6초 동안 뜨는 알림의 '되돌리기'로 원래 자리에 되살린다(연 회차와 포인트는 그대로). 저장된 자료 꼴(`history[{id, ep, scene, done?}]`)은 바뀌지 않았다
- 자막 장면 스토리보드로 보는 재생 화면 체험. 한 회차는 자막 장면 세 개이고 "다음 장면"을 눌러야 넘어간다. 재생 막대·시간·속도는 없다. 셋째 장면 다음에는 다음 화로 저절로 넘어가지 않고 끝 카드(다음 화 제목·첫 자막·버튼)가 나온다
- 작품별 처음 7~10화 무료, 이후 10P로 회차 열기
- 광고 보상 +10P(5초를 끝까지 보면 닫아도 지급, 하루 5번), 100/300/600P 충전 체험, 이용 내역(처음 드리는 4P 포함)
- 작품 공유: 터치 기기에서는 기기의 공유 창, 그 밖에는 링크를 복사하는 앱의 공유 창
- 브라우저 뒤로 가기로 창 → 재생 화면 → 탭을 한 겹씩 닫기(홈으로 돌아오면 보던 탭 유지), 공유 링크(`?drama=`)를 연 뒤 주소 정리
- 찾기: 장르 타일·배너로 들어오면 그 장르로, 메뉴로 들어오면 전체·빈 검색어로 시작
- 처음 온 사람에게 홈에서 한 번 보여 주는 4P 안내 띠(닫으면 `peeka-hint-welcome`에 기록)
- 보관함 저장 취소 되돌리기, 포인트 화면·공유 창·이용 안내에서 들어온 곳으로 돌아가기(포인트 화면에서 돌아오면 보던 스크롤 위치도 되살린다)
- 확인 전 차감하지 않으며 열린 회차를 다시 볼 때 중복 차감하지 않음. 잠금 창·충전 창이 열린 뒤 0.8초 동안은 키보드로 누른 열기·충전을 받지 않는다(Enter를 두 번 눌러 포인트가 나가지 않게)
- 미리보기에서 회차 재생으로 들어갔다 돌아가기, 회차에서 보던 장면과 미리보기 기록 분리

## 체험 범위

실제 드라마 영상, 광고 네트워크, 앱스토어 결제, 회원 서버는 연결되지 않았습니다. 재생 화면은 콘셉트 표지와 예시 자막으로 동작하며 영상 송출을 가장하지 않습니다. 그래서 영상 재생기의 재생 막대·시간·속도·재생/정지 버튼을 두지 않고, 회차를 자막 장면 세 개의 스토리보드로 보여 줍니다. 충전은 실제 금액을 청구하지 않습니다. 예시 가격은 확정 요금이 아닙니다.

포인트·열린 회차·보관함·시청 기록은 현재 브라우저의 localStorage에만 저장됩니다. 어느 화면·창·재생 화면이 열려 있었는지는 저장하지 않으므로 재생 화면에서 새로 고치면 홈의 맨 위에서 다시 시작합니다(보던 회차와 장면은 이어보기에 남아 있습니다). 결제 권한이나 유료 콘텐츠 보호에 사용할 수 없습니다. 상용 버전에서는 서버에서 영수증과 광고 보상을 확인하고, 회차 이용 권한 및 포인트를 일관된 거래로 처리해야 합니다. iOS/Android 설치 패키지를 포함하지 않습니다.

창작마당, 이용자 업로드, 카페, AI 채팅, 구독, 다운로드는 이번 범위에서 제외했습니다.

## 디자인 기준

규칙의 기준 문서는 [DESIGN.md](DESIGN.md)다. 색·글자 크기·간격·모서리·컴포넌트 규칙과, 관리자 사이트와 나눠 쓰는 토큰 구분이 거기에 있다. 아래는 요약이다.

- 뼈대: 라프텔 DESIGN.md의 글자 단계(32·24·18·16·14·12·11), 간격(8·12·16·24·40), 모서리(3·4·8·16·알약)를 빌리고 색·로고·병아리는 peeka 것을 쓴다.
- 모드: 라이트(크림 #FBF4EC)와 다크(먹색 #121214). 위쪽 해·달 버튼으로 바꾸고, 고르지 않았으면 기기 설정을 따른다. 고른 값은 이 브라우저의 localStorage(`peeka-theme`)에만 저장한다.
- 홈: 알약 메뉴(오늘·랭킹·장르) → 화면 폭을 꽉 채운 대표 작품(보던 작품이 있으면 이어보기·TOP 3에 없는 가장 새 작품, 없으면 1위) → 이어보기(가로 썸네일 + 진행 막대, 기록이 있을 때만) → TOP 3(순위 1~3위, 세로 포스터 + 큰 숫자) → 병아리 띠 → 새로 올라온 이야기(최신 5편, 세로 포스터 줄, 전체보기는 최신순 찾기) → 무료 줄 목록(4줄, "7화까지 무료") → 장르 배너.
- 이름: 아래 메뉴의 미리보기 피드는 "빼꼼", 홈 첫 탭은 "오늘"이다. 피드에는 라벤더 "1화 미리보기" 칩이 붙고, 회차 재생은 머리의 "N화 / 전체" 글자로 구분한다. "본편"이라는 낱말은 쓰지 않는다. 시작·이어보기 버튼은 "1화 무료로 보기" / "8화 이어보기" / "9화 보기"(끝까지 본 다음 화) / "24화 다시 보기" 한 가지 규칙을 쓴다.
- 체험판 안내는 "체험판" 표시 하나로, 화면마다 한 번 로고나 화면 제목 옆에만 둔다(광고·충전 창만 창 맨 위에 한 번 더). 자세한 설명은 이용 안내와 앱 정보에 있다.
- 회차 열기·광고·충전 창은 가운데 정렬 하나로 맞춘다. 창의 첫 포커스는 한 가지 규칙이다: 거래 창(잠금·충전)은 주 버튼, 정보 창(작품 소개·회차, 이용 안내, 앱 정보, 공유, 엿보기)은 창 자체, 광고 창은 창 자체에 있다가 5초 뒤 주 버튼. 닫기 ×는 기본 자리가 아니다. 창의 ×는 내려도 오른쪽 위에 붙어 있고, 전체 회차를 열 때 저절로 내려가는 위치는 ×가 저장·공유 버튼을 덮지 않는 곳에서 멈춘다.
- 제목: 화면마다 `h1` 하나. 랭킹·장르 탭 화면은 보이는 제목 없이 낭독용 제목만 둔다. 빼꼼은 피드에 `h1` 하나, 카드 제목은 작품 이름이다.
- 대표 작품 아래 막대 옆에 "1 / 8" 위치 글자가 있다(빼꼼의 작품 순서도 같은 "3 / 8" 꼴). 휴대폰 TOP 3은 셋째가 오른쪽에 걸쳐 보인다.
- 그림 위 글자(자막, 빼꼼 안내 한 줄, 저장·회차·공유 라벨)는 받침 바탕(`--media-back`)을 깔아 밝은 표지에서도 4.5:1 이상을 지킨다.
- 홈 대표 작품은 실제 영상이 아니다. 표지를 천천히 움직이고 예시 자막 두 줄을 한 번씩 보여 준 뒤 첫 줄에 머문다. 아래 메뉴의 지금 메뉴는 색과 함께 채운 아이콘·굵은 글자로 알린다.
- 3초 엿보기: 잠긴 회차를 길게 누르거나(키보드는 회차 칸에서 P 키) 잠금 창·끝 카드의 "3초 엿보기"를 누르면 그 회차를 3초간 보여 주고 시작한 곳(회차 목록, 잠금 창, 재생 화면)으로 돌아간다. 바짝 당긴 그림이 3초에 걸쳐 흐림에서 또렷해지고 자막이 두 박자로 나온다. 포인트를 쓰지 않는다.
- 끝 카드: 셋째 장면을 넘기면 재생 화면 아래에 "8화 끝 / 다음 · 9화 제목 / 첫 자막"과 주 버튼 하나("9화 보기", "10P로 9화 열기", "광고 보고 10P 받기", 광고를 다 봤으면 "포인트 충전하기"), 잠긴 회차에는 "3초 엿보기"가 나온다. 잠금 창은 저절로 뜨지 않고, 포인트는 잠금 창의 열기 버튼에서만 쓴다. 잠긴 다음 화에는 "9화 · 10P · 내 포인트 4P" 한 줄을 적는다. 끝 카드가 나오면 포커스는 늘 끝 카드로 간다. 마지막 화는 "다음으로 볼 작품" 제안 하나와 "처음부터 다시 보기"가 있다. '다음 회차 자동 재생'과 '자막 표시' 설정은 없앴다(저장된 값은 읽을 때 무시한다).
- 잠금 창: 노란 주 버튼 하나, 보조 버튼 하나, 글 링크 한 줄("포인트 충전하기 · 포인트 받는 방법"), 안내 글 한 줄 순서다.
- 재생 화면은 전체 화면 팝업이다. 열리면 포커스가 재생 화면으로 가고 닫히면 재생 화면을 연 버튼(대표 영역·작품 소개의 주 버튼, 이어보기 카드·막대, 시청 기록 줄, 빼꼼의 보기 버튼, 회차 칸)으로 돌아오며 뒤 화면은 조작할 수 없다. →·Space 다음 장면, ← 이전 장면, Shift+N/Shift+P 다음·이전 화(마지막·첫 화에서는 알림으로 답한다), Esc 닫기. 900px 초과 화면에서는 이 키들이 재생 화면 글 영역에 한 줄로 보인다. 빼꼼 피드는 ↑/↓로 넘긴다. 회차 격자는 Tab 한 번에 들어오고 화살표 키로 칸을 옮기며 Home/End로 처음·끝 화로 간다(1000px 이상에서는 안내 줄에 적는다). 창이 떠 있지 않을 때 `/` 키는 찾기 입력란으로 간다. 첫 Tab에는 "본문으로 건너뛰기" 링크가 나온다(처음 열 때 포커스와 스크롤을 옮기지 않는다).
- 이용 안내(내 정보)는 보기 / 회차 열기·포인트 / 체험판·기록 세 묶음이다. 잠금 창과 포인트 화면의 "포인트 받는 방법" 링크는 해당 문항을 바로 열고, 닫으면 원래 창으로 돌아온다. 재생 화면 머리의 "조작 안내" 버튼은 터치 조작 문항을 열고, 닫으면 재생 화면으로 돌아온다.
- 알림은 색이 완료와 주의 두 가지이고(더 갈 화가 없다는 안내는 완료 색에 ⓘ 아이콘) 화면 낭독은 늘 붙어 있는 영역이 읽는다(창 안의 주의 띠 포함). 광고는 시작과 끝만 낭독하고 남은 초는 창 설명에 본문색 글자로 보인다. 저장 공간을 쓸 수 없으면 해결 방법과 함께 한 번만 알린다.
- 1000px 이상에서는 아래 메뉴가 왼쪽 세로 메뉴가 되고 대표 작품은 글과 포스터를 좌우로 나누며 줄 목록은 2열이 된다.
- 병아리 그림은 `public/peeka/`에 자리별 파일(`logo`, `strip`, `loading`, `loading-egg`, `empty`, `locked`)로 두며, 같은 이름으로 덮어쓰면 바뀐다. 탭 아이콘(`public/favicon.ico`, `public/apple-touch-icon.png`)은 `logo.png`에서 만든 것이라 로고를 바꾸면 다시 만든다.
- 모바일 기기 하단 여백, 키보드 초점, 모션 줄이기 설정 반영(표지 움직임·장면 전환·부화·엿보기 연출 정지)

## 개발

원래 생성된 Sites / vinext / React 및 설치된 shadcn 구성요소를 유지합니다. `pnpm dev`, `pnpm build`를 사용합니다. 외부 API 키는 필요 없습니다.

## 추천 미리보기 영상 연결

lib/dramas.ts의 previewSources에 작품별 실제 영상 주소(src)와 한국어 자막 주소(captions)를 함께 지정할 수 있습니다. 현재는 주소가 없으므로 콘셉트 표지 위에 자막 장면 세 개(세 칸 막대와 "장면 1 / 3")로 표시합니다. 재생 위치 막대와 시간 표시는 실제 영상이 있을 때만 나옵니다. 실제 미디어는 playsInline·기본 음소거로 재생하고, 비활성 카드는 정지하며, 로드 실패 시 표지와 실패 안내를 표시합니다. 추천 피드는 회차 시청 기록을 쓰거나 포인트를 사용하지 않습니다.
