# 웹 화면을 front로 통합

## 목표
기존 AI DRAMA 화면과 체험 기능을 Expo 57 / React Native 앱에서 실행한다. 웹 전용 컴포넌트나 WebView에 의존하지 않는다. 실제 영상·결제·광고·로그인 서버 연결은 이번 범위에 포함하지 않는다.

## 구조와 진행
1. `screens`, `components`, `theme`, `assets`에 화면·공통 디자인·리소스를 배치한다.
2. `features/drama`에 작품·포인트·저장·시청 기록을 두고 `services`에서 기기 저장과 공유를 처리한다.
3. Expo Router route에서 화면을 연결한다. 홈/추천/찾기/보관함/내 정보와 상세/재생/포인트를 제공한다.
4. 타입 검사, 포인트 및 기록 규칙 테스트, Android/iOS/Web 번들, 브라우저에서 주요 이용 흐름을 확인한다.

## 성공 기준
- `front`만 설치·실행해 모든 화면에 접근한다.
- 무료 회차 재생, 잠긴 회차 확인, 광고 체험 취소·보상, 중복 차감 방지, 저장·이어보기가 동작한다.
- 추천은 한 화면씩 세로 이동하며 화면을 벗어나면 재생이 멈춘다. 추천은 포인트와 시청 기록을 변경하지 않는다.
- 포스터와 Pretendard 글꼴은 앱 자산으로 포함한다.
- 서버 코드와 기존 프로젝트의 담당 영역 구분을 유지한다.

## 상태
구현 완료 (2026-09-09). `web-prototype`은 기존 공개 사이트의 원본으로 보관하며 `front`에서 참조하지 않는다. 공개 사이트는 이번 작업으로 재배포하지 않았다.

## 검증 결과
- TypeScript 검사 통과.
- 포인트·광고 한도·회차 접근·기록·설정 관련 테스트 8개 통과.
- Expo 57 의존성 호환성 검사 통과. Android/iOS/Web 최종 번들 생성 완료.
- 브라우저 390px 모바일 화면에서 추천 세로 이동·복귀 위치·본편 이동, 검색·상세 이동, 저장·기록·설정 유지 확인.
- 광고 취소 시 보상 없음, 완료 후 4P → 14P, 유료 회차 확인 후 14P → 4P 흐름 확인. 추천 미리보기만으로는 시청 기록이 생성되지 않음.
- 320px 화면에서 홈과 하단 탭 배치 확인. Web에서 지원하지 않는 네이티브 탭 아이콘 렌더링을 플랫폼별 레이아웃으로 분리하고, 수정 이후 브라우저 오류가 없는 것을 확인.
- 실제 iOS/Android 기기 실행은 아직 확인하지 않았다. 번들 생성은 앱 설치·스토어 심사를 대신하지 않는다.
- 영상·광고·충전은 기존 시안과 동일한 체험 기능이며 실제 서비스 연결은 별도 작업이다.
