# fullscreen-episode-playback

## 목표

회차 재생 화면에서 영상 영역을 앱 화면 전체로 확장하고, 화면을 터치하면 뒤로 가기와 재생 컨트롤이 함께 나타나도록 한다.

## 범위와 가정

- 재생 성공 화면만 변경한다. 영상 영역은 공통 `Page`의 여백과 16:9 고정 크기를 사용하지 않고 화면 전체를 차지한다.
- 기존 세로 화면 설정을 유지한다. 영상은 원본 비율을 유지하는 `contain` 방식으로 표시하며, 화면 비율이 다르면 검은 여백을 허용한다.
- 기본 네이티브 컨트롤 대신 화면 위 컨트롤을 사용한다. 터치 시 뒤로 가기, 회차 제목, 재생/일시정지, 재생 위치 탐색을 함께 표시하고 일정 시간 후 숨긴다. 컨트롤을 다시 터치하면 표시 시간을 갱신한다.
- 재생 중 화면 이탈 시 일시정지하는 기존 동작과 로딩·조회 오류·재생 오류 처리를 유지한다.
- 백엔드 API, 다른 화면, 앱 전체 방향 설정, 영상 비율을 무시한 늘이기나 자르기는 범위에 포함하지 않는다. 기존 디렉터리 책임은 바뀌지 않는다.

## 검증

- `npm --prefix front run typecheck`
- `npm --prefix front run test`
- `npm --prefix front run export`
- 완료 기준: 재생 성공 화면의 영상 뷰가 앱 화면을 채우고 원본 비율을 보존한다. 화면 터치로 뒤로 가기와 재생 컨트롤이 함께 나타나고, 재생/일시정지와 위치 탐색이 동작하며, 일정 시간 후 함께 숨는다. 뒤로 가기와 화면 이탈 시 재생 상태가 올바르게 처리된다.
- 실제 Android/iOS 기기에서는 세로 화면의 검은 여백, 시스템 안전 영역, 터치·탐색·자동 숨김·뒤로 가기 동작을 확인한다. 자동 명령은 네이티브 터치와 영상 렌더링을 검증하지 않는다.

## 승인 및 실행 상태

- 범위 승인: 원본 비율을 유지하고 검은 여백을 허용하는 전체 화면 재생과 함께 표시되는 뒤로 가기·재생 컨트롤.
- task 구성 승인: `front/src/screens/EpisodePlaybackScreen.tsx` 한 파일을 수정하는 단일 task와 선언된 세 검증 명령.
