# 프론트 내 정보·포인트 화면 연결

## 목표

`front`의 내 정보 화면을 승인된 웹 시안의 메뉴 구성으로 교체하고, 포인트 화면으로 이동할 수 있게 한다. 현재 구현되지 않은 포인트 조회·적립·충전·사용은 화면에서 준비 중임을 명확히 표시한다.

## 범위와 가정

- 내 정보 화면은 `MY SPACE` 제목, 게스트 프로필과 체험 계정 표시, 포인트 카드, 포인트 이용 내역·시청 기록·재생 설정·이용 안내·앱 정보 메뉴로 구성한다. 기존 `보관함` 섹션과 `저장한 작품` 버튼은 제거한다.
- 포인트 카드와 포인트 이용 내역 메뉴는 새 포인트 화면으로 이동한다. 이용 내역 메뉴는 해당 탭을 바로 연다. 시청 기록 메뉴는 기존 보관함의 시청 기록 탭으로 이동한다.
- 재생 설정·이용 안내·앱 정보 메뉴는 내 정보 화면의 읽기 전용 안내 모달을 연다. 재생 설정에서 지원하지 않는 조작은 비활성으로 표시한다.
- 포인트 화면에는 뒤로 가기, 잔액 영역, `충전하기`·`이용 내역` 탭, 광고 보상과 충전 상품의 예시 영역, 내역 안내를 표시한다. 실제 잔액을 알 수 없으므로 `— P`와 준비 중 문구를 사용하며, 예시 상품·보상은 비활성으로 표시한다.
- 포인트 값 변경, 로컬 영속 저장, 회차 해제, 실제 광고·결제, 인증, 백엔드 및 API 계약 변경은 범위 밖이다. 기존 회차 가격 표시는 유지한다.
- 화면과 경로는 `front/src/screens/`와 `front/src/app/`의 기존 책임을 따른다. 디렉터리 책임 변경은 없다.

## 실행 순서 및 병렬 작업

- `task-1`은 완료됐다.
- `task-2`는 같은 `AccountScreen.tsx`를 수정하므로 `task-1` 완료 후 실행한다. 함께 실행할 다른 task는 없다.

## 검증

- `npm --prefix front run typecheck`
- `npm --prefix front run test`
- `npm --prefix front run export`
- 완료 기준: 내 정보의 포인트 카드와 이용 내역 메뉴가 각각 포인트 화면의 `충전하기`, `이용 내역` 탭을 열고 뒤로 가기가 작동한다. 시청 기록 메뉴는 기존 시청 기록 탭으로 이동한다. 재생 설정·이용 안내·앱 정보 메뉴는 안내 모달을 열고 닫는다. 포인트 화면은 데이터가 없는 상태를 사실대로 표시하며 포인트를 변경하는 동작이 없다.
- 추가 완료 기준: 재생 설정·이용 안내를 닫을 때 종료 애니메이션 중 앱 정보 내용이 나타나지 않는다. 앱 정보 자체도 정상적으로 열고 닫힌다.
- 자동 명령은 내비게이션 터치와 모달 표시를 직접 검증하지 않으므로, 실행 단계에서 웹 또는 기기 화면의 진입·탭·뒤로 가기 결과도 확인한다.

## 승인 및 실행 상태

- 범위 승인: `front`의 내 정보·포인트 화면 연결만 수행하며 로컬 포인트 체험과 백엔드 작업은 제외한다.
- task 구성 승인: 웹 시안의 내 정보 메뉴 구성으로 교체하고 보관함 섹션·저장한 작품 버튼을 제거하는 단일 task와 위 파일·검증 명령.
- 계획 상태: `task-1` 완료, 팝업 닫힘 문제를 해결하는 `task-2` 대기 중. `task-2`는 `$harness` 실행 전까지 제품 코드를 변경하지 않는다.
