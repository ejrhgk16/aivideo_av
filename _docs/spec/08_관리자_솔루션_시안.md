# 08. 관리자 솔루션 시안 (웹 전용 화면 프로토타입)

> 작성 2026-11-06 · 상태 `[시안]` · 코드: `front/src/app/admin/`, `front/src/screens/Admin*Screen.tsx`, `front/src/components/adminUi.tsx`, `front/src/features/admin/`

## 1. 목적

작품·회차 성과를 광고 매체 기준 지표로 보고, 새 작품·회차를 올리는 운영 화면의 **클릭 가능한 시안**이다.
서버 호출·실제 업로드는 없고, 고정 기준일(2026-11-05 KST)로 만든 **결정적 샘플 데이터**(작품 4개, 회차 6~12개, 최대 180일 일별 수치)를 쓴다.
로그인 화면을 뺀 모든 관리자 화면 상단에 `샘플 데이터` 배지와 "수집 기능이 연결되기 전까지 모든 수치와 목록은 화면 확인용 예시"라는 안내를 표시한다(로그인 화면은 `샘플` 배지와 시안 안내).

## 2. 용어 `[확정]`

| 화면 표기 | 뜻 | 코드 |
|---|---|---|
| 프로젝트 | 작품(drama) | `AdminProject` |
| 캠페인 | 회차(episode) | `AdminCampaign` |

- "프로젝트·캠페인"은 **관리자 화면 문구**에만 쓴다. 공용 코드·API 이름은 작품/회차 기준을 유지하며, 홈 배너의 `HOME_CAMPAIGN`(캠페인 배너)과는 다른 뜻이다.

## 3. 지표 정의 `[확정]`

| 지표 | 정의 |
|---|---|
| 노출수 (Impressions) | 작품·회차 카드가 화면에 50% 이상, 1초 이상 보인 횟수 |
| 조회수 (Views) | 3초 이상 재생된 횟수 |
| 조회율 (View rate) | 조회수 ÷ 노출수 |
| 평균 시청 비율 (Avg. % viewed) | 총 시청 시간 ÷ (조회수 × 회차 길이). 기획에서 "시청률"로 부르던 값이며 TV 시청률과는 다르다 |
| 완주율 (Completion rate) | 90% 이상 시청한 조회 ÷ 조회수 |
| 이탈률 (Exit rate) | 1 − 완주율 |
| 구간 이탈 곡선 (Retention) | 회차 길이의 5%마다(0~100%) 아직 시청 중인 조회의 비율. 가장 크게 떨어진 5% 구간을 강조한다 |

- 분모가 0이면 비율은 `–`로 표시한다(NaN·Infinity 없음).
- 기간은 최근 7일 / 28일 / 90일(KST, 기준일 포함). 증감은 바로 앞 같은 길이 기간과 비교하며, 횟수는 %, 비율은 %p로 ▲/▼ 기호와 개선/악화 글자를 함께 표시한다.
- 이전 기간이 시작될 때 공개된 캠페인이 하나도 없으면(예: 이전 기간 중에 공개된 회차) 증감 대신 "비교 데이터 없음"을 표시한다.
- 여러 회차를 합칠 때 평균 시청 비율의 분모는 회차별 `조회수 × 회차 길이`의 합이다.

## 4. 화면과 경로

웹에서만 연다. 네이티브 앱에서 `/admin` 경로는 홈(`/`)으로 돌려보낸다. 기간은 `?range=7|28|90` 쿼리로 화면 간에 유지한다.

| 화면 | 경로 | 내용 |
|---|---|---|
| 관리자 로그인 | `/admin/login` | 사이드바 없는 가운데 카드. `샘플` 배지와 시안 안내, 이메일·비밀번호(첫 제출 후 형식·8자 이상 검사, 비밀번호 칸 Enter로 제출), `로그인`. **서버 호출 없이** 통과 처리 |
| 프로젝트 목록 | `/admin` | 기간 선택, 전체 KPI(노출수·조회수·조회율·평균 시청 비율·이탈률)와 증감, 프로젝트 표(정렬, 행 클릭 → 상세) |
| 프로젝트 상세 | `/admin/projects/[projectId]` | 상태·장르·캠페인 수·소개, 프로젝트 KPI, 캠페인 표(정렬, 행 클릭 → 대시보드), `캠페인 추가` |
| 캠페인 대시보드 | `/admin/campaigns/[campaignId]` | KPI 6종과 증감, 일별 조회수·조회율, 구간 이탈 곡선(최대 이탈 구간 표시), 25/50/75/100% 도달률, 지표 정의 |
| 업로드 | `/admin/upload` (`?projectId=`) | 새 프로젝트 / 기존 프로젝트에 캠페인 추가. 필수 입력·회차 번호 중복·공개 예정 일시(실제 날짜, 기준일 이후) 검사 후 **저장 없이** 완료 안내만 표시 |

- 시안 로그인 게이트: `/admin/login` 외 관리자 화면은 로그인 전이면 `/admin/login`으로, 로그인 후 `/admin/login`을 열면 `/admin`으로 보낸다. 로그인하면 `/admin`으로 이동한다. 로그인 여부와 이메일은 웹 관리자 레이아웃이 들고 브라우저 탭의 `sessionStorage`에만 둬서 새로고침해도 유지되고 탭을 닫으면 사라진다. 넓은 화면은 사이드바 아래에 이메일과 `로그아웃`, 좁은 화면은 `나가기`만 두고, 누르면 로그인 화면으로 돌아간다. 실제 인증·권한 확인은 없다.
- 없는 프로젝트·캠페인 주소는 빈 화면 안내와 `프로젝트 목록으로` 버튼을 보여준다.
- 업로드 필수 항목: (새 프로젝트) 제목·장르·포스터 이미지, (캠페인) 회차 번호(기본값 다음 번호)·캠페인 제목·영상 파일·가격 포인트(0 = 무료)·공개 예정 일시(`YYYY-MM-DD HH:mm`, KST). 소개·표지 이미지는 선택.
- 파일은 웹 파일 선택 창으로 고르고 이름·크기만 표시한다. 입력값은 화면을 떠나면 사라진다.
- 구간 이탈 곡선·도달률은 공개 이후 전체 기간 기준이다(기간 선택과 무관).

## 5. 실데이터 전환에 필요한 서버 작업 `[제안]`

| 영역 | 필요한 작업 |
|---|---|
| 노출 이벤트 | 앱이 카드 노출(50% 이상·1초 이상)을 화면·위치·작품/회차와 함께 묶어 전송. 중복 제거 키, 게스트 포함 |
| 재생 세션 이벤트 | 재생 시작·주기적 heartbeat(재생 위치)·종료/이탈 위치를 세션 ID로 전송. 탐색(seek)·배속 처리 기준 확정 |
| 조회·완주 판정 | 세션별 3초 이상 재생 = 조회, 회차 길이의 90% 이상 도달 = 완주. 5% 구간별 최대 도달 위치 저장 |
| 일별 집계 | KST 날짜 기준 회차별 일 집계(노출·조회·완주·총 시청 시간·5% 구간 도달 수) 배치와 재집계 절차 |
| 관리자 인증 | 시안 로그인 게이트를 서버 인증으로 교체. 관리자 API 서버 측 OPERATOR 역할 guard, 비밀번호 해시 저장(평문 금지), FN-ADM-01의 2단계 인증(이메일+2FA), 관리자 API 접근 기록 |
| 업로드·인코딩 | 영상·이미지 업로드(서명 URL 등), 인코딩·썸네일 작업 상태, 공개 예약 시각 처리, 회차 번호 중복 검사 |

전환 시 관리자 API는 `_docs/api/`에 계약을 추가하고, 화면의 샘플 데이터 모듈을 API 호출로 교체한다.
