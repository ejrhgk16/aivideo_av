# AI DRAMA 상세 기획서 (v1.0)

AI 숏폼 드라마 앱의 **개발용 상세 기획서**다. 2026-09-09 PPT 기획서(`_docs/AI_DRAMA_기획서_구현안내_20260909.pptx`)가 화면당 2~3줄 설명이라 구현 기준으로 쓰기 어려워,

> **구현 기준 (2026-10-21)**: 코드·데이터 모델·API의 기준은 **개발자 코드**(GitHub `dev`)와 개발자 문서(`_docs/ARCHITECTURE.md`, `_docs/api/`)다. 이 기획서는 제품 요구사항·정책·화면 기준이며, 06 데이터·API 초안과 개발자 문서가 다르면 개발자 문서가 우선한다. 차이는 개발자와 합의해 맞춘다.

- 기준 화면: 2026-09-09 앱 코드 `front/src/screens/*.tsx`(화면설계서 §4의 현재 화면 분석 시점)

## 용어 사전

| 용어 | 뜻 |
|---|---|
| 작품 | 하나의 드라마 시리즈(예: 마지막 신호) |
| 회차 | 작품의 한 편. 약 1분 |
| 무료 구간 | 작품별로 정한 처음 7~10화. 누구나 무료로 본다 |
| 회차 열기 | 무료 구간 이후의 잠긴 회차를 포인트로 볼 수 있게 만드는 것. 한 번 열면 다시 볼 때 무료 |
| 포인트(P) | 앱 안에서 쓰는 재화. 충전으로 사는 **유상 포인트**와 광고·이벤트로 받는 **무상(보너스) 포인트**가 있다 |
| 광고 보상 | 광고를 끝까지 보면 받는 무상 포인트 |
| 충전 | 앱스토어/구글플레이 결제로 유상 포인트를 사는 것 |
| 추천 피드 | 추천 탭의 세로 넘겨보기 화면. 예고·1화 미리보기를 본다(포인트·기록 변화 없음) |
| 이어보기 | 마지막으로 본 회차·위치부터 다시 재생 |
| 찜 | 작품을 보관함에 담기. 북마크 아이콘, 보관함 탭 "찜한 작품". 현재 화면 일부의 "저장"·"+"는 "찜"으로 바꾼다(2026-10-12 확정) |
| 편성 | 운영자가 홈에 어떤 작품을 어떤 순서로 보여줄지 정하는 것 |
| 게스트 | 로그인하지 않은 사용자. 서버에 익명 계정이 자동으로 만들어진다(제안) |
| 원장(ledger) | 포인트가 들어오고 나간 기록. 고치지 않고 계속 쌓는다 |
| 지급 건 · 소비 배분 | 포인트를 받은 묶음 하나하나(예: 광고 10P, 충전 100P)와, 회차를 열 때 어느 묶음에서 얼마를 썼는지의 기록. 소멸·환불 계산의 기준 |
| 거래(transaction) | 사용자 요청 1건(회차 열기 1번, 충전 1번). 중복 처리를 막는 단위 |
| SSV | 광고 회사가 "이 사람이 광고를 끝까지 봤다"고 우리 서버에 직접 알려주는 확인 방식 |
| 멱등(idempotent) | 같은 요청이 여러 번 와도 결과가 한 번 처리한 것과 같게 만드는 것(중복 차감 방지) |
| 시트 | 화면 아래에서 올라오는 창(회차 열기, 회차 목록 등) |
