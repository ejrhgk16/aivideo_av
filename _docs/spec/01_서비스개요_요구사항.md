# 01. 서비스 개요 · 요구사항

> 이 앱이 **무엇이고, 누구를 위해, 어디까지 만드는지**를 정의한다. 개발 범위 판단이 애매할 때 §3(범위)과 §6(미결정 사항)을 본다.

### 1-1. 왜 만드나 (문제와 기회)

- 출퇴근·대기 시간처럼 **짧은 틈**에 볼 콘텐츠 수요가 크다. 1분 회차는 이 틈에 딱 맞는다.
- 숏폼 드라마는 **회차마다 끝에 궁금증(클리프행어)** 을 남겨 다음 화를 보게 만드는 구조라, 무료 구간 → 유료 전환 모델과 잘 맞는다.
- AI 제작으로 **제작비와 제작 기간을 크게 줄여** 많은 작품을 빠르게 시험하고, 반응 좋은 장르에 집중할 수 있다.

### 1-2. 타깃 사용자 `[제안]`

| 구분 | 설명 | 이 앱에서 원하는 것 |
|---|---|---|
| 주 타깃 | 20~40대, 출퇴근·점심시간에 휴대폰으로 짧은 영상을 보는 사람 | 바로 몰입되는 짧은 이야기, 돈 안 내고도 볼 수 있는 방법(광고) |
| 유료 전환 타깃 | 웹소설·웹툰 회차 결제에 익숙한 사람 | 다음 화가 궁금할 때 빠르게 열기, 결제 부담이 작은 소액 상품 |
| 유입 경로 | SNS 숏폼 광고(릴스·쇼츠·틱톡)에서 하이라이트를 보고 설치 | 광고에서 본 작품으로 바로 이동(딥링크) |

### 1-3. 핵심 가치

1. **1분이면 빠져드는 이야기** — 앱을 열자마자 재생까지 3탭 이내.
2. **돈 없이도 이어볼 수 있다** — 무료 구간 7~10화 + 광고 보상으로 포인트를 모아 다음 화. ("광고 1회 = 회차 1개"는 가격·보상량이 확정되면 그때 약속한다.)
3. **내가 쓴 포인트는 확실하게** — 한 번 연 회차는 작품 제공 기간 동안 추가 차감 없이 재시청. P0에서는 차감 전 항상 확인.

### 6-1. 미결정 정책의 출시 차단 기준

권장안을 개발·검증 환경에서 구현할 수는 있지만 문서 수정만으로 승인된 것은 아니다. 기획 담당이 결정 내용·승인일을 기록하고, 법률·스토어 검토가 필요한 항목은 그 결과를 함께 반영한다.

| 미결정 묶음 | 확정해야 할 내용 | 확정 전 제한 |
|---|---|---|
| Q-02·03·24 | 게스트 유료 허용, 로그인 수단, 연령·필수 동의 순서와 검증 방법 | 실제 사용자 계정·광고·결제 공개 금지 |
| Q-04~09 | 상품·회차 가격, 광고 보상·한도, 무상 유효기간·소비 순서, 환불 원구매 배분·부족분·보너스 회수 | 실제 과금·광고 지급 공개 금지. 유상 포인트 무만료는 선택 대상이 아님 |
| Q-09·11 | 탈퇴 시 미정산 거래 처리·연락 방법·처리 기한, 제공 종료 보상과 반환분 유효기간, 일시 숨김 장기화 처리 | 약관·CS·운영 처리 계약 완료 전 유료 콘텐츠 출시 금지 |
| Q-10 | 신규 지급 여부와 재설치·병합 중복 판별 | 미승인 웰컴 포인트 실제 지급 비활성화 |
| Q-12·13·14 | 콘텐츠 등급·권리, AI 고지 적용·표시, 제휴 계약상 보호 수준 | 승인 증빙 없는 작품 공개 금지 |
