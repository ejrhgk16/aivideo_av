2. **[사실]** 국내 업체 공개 가이드는 화면 그림뿐 아니라 요소별 동작·분기·오류·데이터 출처·권한을 요구한다. 근거: A3·A4.
3. **[제안]** 요구사항→기능→화면→정책→검수 ID를 연결하고, 미결정 항목에는 담당자·결정기한을 둔다. 근거: A3·A7, 프로젝트 기획 결정(01 문서).
4. **[기획 결정]** 출시 핵심은 운영팀 등록 콘텐츠, 작품별 무료 회차, 포인트 해제, 해제 회차 재시청이다. 구독·다운로드·창작마당·카페·AI 채팅은 제외한다. 기획 결정(01 문서)
5. **[사실]** ShortMax는 구매 코인부터 쓰고 보너스는 나중에 쓰도록 규정한다. 무료 포인트 우선 사용을 경쟁사의 공통 규칙으로 단정하면 안 된다. 근거: B4.
6. **[사실]** Apple은 인앱결제로 구매한 크레딧의 만료를 금지한다. 국내 웹툰의 유료 쿠키 만료 정책을 그대로 복사하지 않는다. 근거: C1·B17.
7. **[제안]** 자동 재생과 자동 차감을 분리하고, MVP에서는 유료 회차마다 가격·잔액을 보여준 뒤 확인받는다. 기획 결정(01 문서), B.4.
8. **[사실/제안]** 광고 완료는 광고사 서버 검증을 근거로 지급하고 중복 지급을 차단한다. 시안의 5초·하루 5회는 실제 광고 정책이 아니다. 근거: C8·C9, 기획 결정(01 문서).
9. **[사실]** 계정 삭제, SDK 데이터 공개, 추적 동의, 광고성 알림 동의, 청약철회 안내는 출시 설계에 반영해야 한다. 근거: C2~C7·K1~K6.
10. **[사실/제안]** AI 표시와 영상 등급을 운영 등록 단계에 포함하고, 보상 홍보용 Live Activities는 일반 알림으로 대체한다. “로빈후드” 광고사는 미확인이다. 근거: K8~K10·C10, C.4.

| 3 포인트로 열기 | b≥p일 때 활성. 확인 후 서버가 잔액 차감과 시청 권한 부여를 함께 처리. 응답 대기에는 반복 누름 차단 |

### C.3 보상형 광고의 지급·서버 검증(AdMob SSV)

SSV는 **Server-Side Verification**, 광고사의 보상 완료 정보를 앱 화면 대신 서버로 받아 진위를 확인하는 방식이다. AdMob이 제공하는 기능이며, 모든 광고사에 동일한 필드/서명이 있는 것은 아니다.
