# 04. 기능명세서

> 앱·서버·운영자 웹에서 만들어야 할 기능을 **한 줄에 하나씩** 나열한 목록이다. 개발 작업(이슈) 단위로 쪼갤 때 이 표의 기능 ID를 쓴다.
> 화면 위치는 [05_화면설계서](./05_화면설계서.md), 규칙은 [03_정책정의서](./03_정책정의서.md), 데이터·API는 [06_데이터_API_초안](./06_데이터_API_초안.md).

## 읽는 법

| 열 | 뜻 |
|---|---|
| 기능 ID | `FN-<영역>-<번호>`. 영역 코드는 화면 ID와 같다 |
| 우선순위 | **P0** 출시 필수(MVP) · **P1** 출시 직후 1차 업데이트 · **P2** 향후 검토 |
| 현재 상태 | **UI완료** 화면·기기 내 로직이 있는 시안. 운영용 API·상태·예외 연동 완료를 뜻하지 않음 · **체험** 가짜 흐름(광고·결제·영상)이라 실제 연동 필요 · **미구현** 새로 만들어야 함 |
| 정책 | 03 정책정의서의 절 번호 |

---

> 표의 `4P`, `10P`, `5회`, 상품 가격과 고정 시간은 별도 확정 표시가 없으면 **현재 시안/설명 예시**다. 출시 화면은 승인된 서버 정책·스토어 가격을 표시한다. 정책별 승인 조건은 01 §6을 따르며, P0라고 해서 제안 정책이 승인된 것은 아니다.

## 14. P0 완료 기준 (개발 완료 판정용)

각 항목은 실제 기기(iPhone 1대 이상, Android 1대 이상)에서 확인한다.

**시청**
- [ ] 무료 회차는 로그인 없이 끊김 없이 재생되고, 끝나면 다음 무료 회차가 자동 재생된다(자동 재생 켬).
- [ ] 무료 구간 다음 회차에서 재생이 멈추고 회차 열기 시트가 뜬다. 시트를 닫으면 포인트가 변하지 않는다.
- [ ] 재생 화면에서 나갔다가 다시 들어오면 같은 회차·위치(±2초)부터 재생된다. 앱을 지웠다 다시 깔아도 같은 계정이면 유지된다.
- [ ] 추천 피드를 아무리 넘겨도 포인트와 시청 기록이 바뀌지 않는다.

**회차 열기·포인트**
- [ ] 잔액이 충분할 때 "10P로 N화 보기"를 빠르게 5번 눌러도 10P만 차감되고 회차가 열린다.
- [ ] 한 번 연 회차는 다른 기기·재설치 후에도 추가 차감 없이 재생된다.
- [ ] 요청 전에 오프라인이면(비행기 모드) 차감 없이 오류 안내가 뜬다.
- [ ] 요청을 보낸 뒤 응답을 못 받고 앱을 껐다 켜면, 같은 거래를 조회해 결과를 복구하고 최종적으로 한 번만 차감된다.
- [ ] 무상 6P + 유상 4P 상태에서 10P 회차를 열면 두 지급분에서 나뉘어 차감되고, 포인트 내역과 지급 건별 남은 양이 일치한다.
- [ ] 시트를 연 사이 운영자가 가격을 바꾸면 차감되지 않고 새 가격으로 다시 확인을 받는다.
- [ ] 두 기기에서 서로 다른 요청으로 같은 회차를 동시에 열어도 한 번만 차감된다.
- [ ] 포인트 내역에 모든 지급·차감이 일시·내용·증감과 함께 남는다.

**광고 보상**
- [ ] 광고를 끝까지 보면 서버 지급 확인 후 잔액이 오른다. 중간에 닫으면 오르지 않는다.
- [ ] 하루 한도를 모두 예약/사용하면 추가 광고 시작을 거절한다. 이미 예약하고 완료한 광고의 유효 SSV는 한도 변경·자정·앱 종료와 관계없이 한 번 지급한다.
- [ ] 회차 열기 시트에서 광고를 본 뒤 같은 시트로 돌아오며, 회차는 자동으로 열리지 않는다.

**충전**
- [ ] 스토어 결제 성공 시 서버 검증 후 정확한 포인트가 1번만 지급된다.
- [ ] 결제 직후 앱을 강제 종료해도 다시 열면 포인트가 지급된다.
- [ ] 스토어에서 환불되면 해당 구매에서 지급된 유상·보너스 포인트 중 회수 가능분과 부족분을 구분해 내역에 남긴다. 현재 잔액을 음수로 만들거나 다른 구매분을 임의 회수하지 않는다.

**가격·연령·용어**
- [ ] 어드민에서 회차 가격을 바꾸면 앱 업데이트 없이 모든 화면의 가격 문구가 바뀐다. 이미 연 회차는 영향이 없다.
- [ ] 생년월일상 12세 사용자는 15세 작품을 목록에서 볼 수 있지만 재생·회차 열기는 할 수 없다. 청소년관람불가 작품은 목록·검색·피드에 나오지 않는다.
- [ ] 만 14세 미만 사용자는 보호자 동의 전에 충전·광고성 알림이 막혀 있고, 무료 시청·찜은 된다.
- [ ] 앱 어디에도 "저장"·"+"로 된 찜 버튼이 남아 있지 않다(모두 "찜"·북마크).

**계정·스토어 심사**
- [ ] 게스트가 로그인 없이 충전할 수 있고, 충전 전에 계정 미연동 경고를 본다.
- [ ] 게스트로 쌓은 포인트·열린 회차가 로그인 후에도 그대로다.
- [ ] 앱 안에서 회원 탈퇴를 끝까지 진행할 수 있다(게스트는 "이 기기 데이터 삭제"). 웹 삭제 요청 페이지 URL이 동작한다.
- [ ] 광고를 본 뒤 부적절한 광고를 신고할 수 있다.
- [ ] 충전 화면에서 결제 전에 청약철회 조건과 미성년자 결제 취소 안내를 볼 수 있다.
- [ ] 유상(충전) 포인트의 `expiresAt`은 항상 비어 있고, 소멸 배치가 유상분을 줄이지 않는다. 화면에는 "소멸 없음"만 표시한다. 오래전에 충전한 유상 포인트도 그대로 쓸 수 있다.
- [ ] 남은 광고 기회가 1회일 때 두 기기에서 동시에 광고를 시작하려 하면 한 쪽만 시작되고, 끝까지 본 쪽은 반드시 보상을 받는다.
- [ ] 스토어 환불 알림이 와도 회수량은 원래 지급량을 넘지 않고, 같은 알림이 두 번 와도 한 번만 회수된다.
- [ ] 약관·개인정보 처리방침을 앱 안에서 열 수 있다.
- [ ] 최소 지원 버전을 올리면 구버전 앱에 업데이트 안내가 뜬다.
