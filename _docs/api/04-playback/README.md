# Playback API

저장 영상, 시청 진행, 시청기록 조회, 회차 재생 API를 관리할 도메인이다.

- [회차 재생 URL](./episodes.md): 현재 재생 URL 계약과 JWT 전환 예정 설계(무료 익명 허용·유료 구매 권한 확인)
- [시청기록 저장](./watch-progress.md): 로그인 사용자의 본편 FULL·작품 PREVIEW 영상별 재생 시작·2/3 도달 기록 저장
- [시청기록 조회](./watch-history.md): 로그인 사용자의 공개 본편·미리보기 시청 이력과 30개 페이지 조회
- [저장 영상](./saved-videos.md): 로그인 사용자의 본편·미리보기 영상 저장·해제와 30개 페이지 조회
